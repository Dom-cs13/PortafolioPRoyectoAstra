A Language
Born From
The Cosmos

ASTRA is not a framework built on top of existing tools. It is a purpose-built domain-specific language with its own lexer, parser, and multi-pass optimizing compiler. Every syntactic construct maps directly to a physical simulation primitive — atmospheric pressure gradients, stellar flux calculations, biochemical equilibrium states.

The compiler pipeline transforms high-level habitability queries into parallelized numerical simulations, reducing what would require weeks of supercomputer time into seconds of deterministic execution.

mission Kepler442b_Habitability {

  // — Stellar Parameters ————————
  star KIC_8462852 {
    type  = K_DWARF
    flux  = 0.74 S☉
    age   = 4.2e9 yr
  }

  // — Planetary Body ————————————
  planet target {
    mass       = 2.34 M♁
    radius     = 1.34 R♁
    orbit_semi = 0.409 AU
    eccentricity = 0.04
  }

  // — Atmosphere Model ——————————
  atmosphere {
    N2  = 78.1%
    O2  = 20.9%
    CO2 = 0.04%
    albedo = 0.31
    greenhouse_factor = auto
  }

  // — Simulation Pipeline ———————
  simulate {
    duration   = 1e6 yr
    resolution = HIGH
    outputs    = [
      SURFACE_TEMP, LIQUID_WATER,
      BIOSIG_SPECTRUM, ESI_INDEX
    ]
  }

  // — Viability Gate ————————————
  assert viable_if {
    ESI_INDEX    > 0.85
    SURFACE_TEMP in [273, 323] K
    LIQUID_WATER > 0.0
  }
}
